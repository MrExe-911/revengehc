Taruh file icon untuk tim (guild) BetterTeams di sini.

NAMA FILE HARUS PERSIS SAMA dengan NAMA TIM (field "name" di file .yml tim
tersebut, persis termasuk huruf besar/kecil dan spasi), plus ekstensi .png.
Contoh: kalau nama timnya "Dragon Slayers", file icon-nya:

  public/iconteam/Dragon Slayers.png

Kalau tim tertentu tidak punya file icon di sini, halaman Team otomatis
menampilkan kepala Minecraft si OWNER tim itu sebagai gantinya (lewat
minotar.net). Kalau owner-nya juga tidak bisa dideteksi, tampil ikon
generik. Tidak perlu isi semua tim — cukup yang mau kamu kasih icon custom.

CATATAN: karena pakai nama tim (bukan ID unik), kalau ada 2 tim dengan nama
PERSIS sama, keduanya akan pakai file icon yang sama. Kalau itu terjadi dan
kamu mau bedakan, ganti salah satu nama tim di game (lewat command BetterTeams)
supaya unik.

Rekomendasi ukuran: persegi (1:1), minimal 128x128px.
